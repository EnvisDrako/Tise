# Taset Academy - Images Directory

This directory contains all images and visual assets for Taset Academy website.

## Directory Structure

```
images/
├── logos/          # Logo files
├── icons/          # Icon files and favicons
├── banners/        # Banner images for homepage and sections
└── README.md       # This file
```

## Required Logo Files

### Main Logos
Place your logo files in the `logos/` folder:

1. **logo.png** - Main logo (recommended: 300x80px, transparent background)
   - Used in: Header navigation, structured data
   
2. **logo-white.png** - White version of logo (for dark backgrounds)
   - Used in: Footer
   
3. **logo-square.png** - Square version (recommended: 512x512px)
   - Used in: Social media sharing, app icons

### Favicon Files
Place favicon files in the `icons/` folder:

1. **favicon.ico** - Standard favicon (16x16, 32x32, 48x48)
2. **favicon-16x16.png** - 16x16 PNG favicon
3. **favicon-32x32.png** - 32x32 PNG favicon
4. **apple-touch-icon.png** - Apple touch icon (180x180px)

### Banner Images
Place banner images in the `banners/` folder:

1. **hero-banner.jpg** - Homepage hero banner (recommended: 1920x600px)
2. **about-banner.jpg** - About page banner
3. **courses-banner.jpg** - Courses page banner
4. **contact-banner.jpg** - Contact page banner

### Social Media & SEO
1. **og-default.jpg** - Default Open Graph image (1200x630px)
   - Used when sharing pages on social media

### Certification Logos
1. **cert-iso.png** - ISO certification logo
2. **cert-accredited.png** - Accreditation logo

## Image Guidelines

### File Formats
- **Logos**: PNG with transparent background
- **Photos**: JPG (optimized for web)
- **Icons**: PNG or SVG
- **Favicons**: ICO and PNG

### Size Recommendations
- **Logos**: Max width 300px, maintain aspect ratio
- **Banners**: 1920px wide, 400-800px height
- **Social sharing**: 1200x630px (Facebook/LinkedIn), 1024x512px (Twitter)
- **Thumbnails**: 400x300px

### Optimization
- Compress all images before uploading
- Use tools like TinyPNG, ImageOptim, or Squoosh
- Target file sizes:
  - Logos: < 50KB
  - Banners: < 200KB
  - Photos: < 150KB

## How to Add Images

1. Place your logo files in `logos/` folder
2. Place favicon files in `icons/` folder
3. Place banner images in `banners/` folder
4. Ensure file names match exactly as specified above
5. Clear browser cache to see changes

## Fallback Behavior

If logo images are not found:
- Header will show: 🎓 Taset Academy (text with icon)
- Footer will show: 🎓 Taset Academy (text with icon)

This ensures the site remains functional while awaiting proper logo files.
